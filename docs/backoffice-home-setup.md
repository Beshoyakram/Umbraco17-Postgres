# Backoffice-only Home content

Home, Header, and Footer **no longer use hardcoded fallbacks**.

## Apply content
1. Restart the site
2. Umbraco → **Settings → uSync → Import** (Content + Media)
3. Open **Content → Home** and confirm all tabs are filled
4. Open **Global Site Settings → Main Info / Footer** for logo and contact

## Edit later
Change text/images only in backoffice — publish to update the website.
